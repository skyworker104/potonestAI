# 대화 검색 질의 유형과 기대 동작

사용자가 이 장비(가정용 사진 서버)에 말로 사진을 찾을 때 쓰는 질의를 유형별로 정리하고,
각 유형이 어떻게 해석·검색·설명되어야 하는지 정의한다.

- **실행 기준표**: `tests/test_query_cases.py` (이 문서의 표와 1:1로 맞춘다)
- **조건 해석 규칙**: `backend/query_frame.py`
- **대화 처리 순서**: `backend/main.py` `chat()`

새 표현을 지원하거나 동작을 바꿀 때는 ① 이 문서에 유형/예를 추가하고 ② 기준표에 행을
추가한 뒤 ③ 규칙을 고친다. 기준표가 통과하지 않으면 배포하지 않는다.

---

## 1. 기본 원칙

1. **질의 = 조건 + 내용.** 한 문장은 "어떤 사진을 거를지"(조건)와 "사진에 무엇이 보이는지"(내용)로
   나뉜다. 조건은 규칙으로 확정하고, 내용만 LLM·이미지 검색에 맡긴다.
   - 조건어가 내용으로 새면 엉뚱한 결과가 난다: "최근 업로드된"을 이미지로 찾기, "여행"을 AND로 묶어
     236장 중 2장만 찾기, "Jirisan"을 이미지로 찾기 등 실사례.
2. **조건 말은 문장에서 지운다.** LLM은 남은 말(residual)만 본다.
3. **내용이 없으면 LLM을 부르지 않는다.** 조건만으로 검색한다(빠르고 결과가 흔들리지 않는다).
   조건도 내용도 없을 때만 LLM이 잡담/검색을 판단한다.
4. **모든 결과에 해석을 보인다.** 답변 문장 + 설명 줄(📅⬆️📍🔎➖…)에 무엇을 조건으로 썼고 무엇을 뺐는지.
5. **정직하게 센다.** 상한(기본 1000장, 내용 검색 60장, 요청 N장)에 걸리면 실제 전체 수를 밝힌다.

## 2. 처리 순서 (`chat()`)

| 순서 | 단계 | 예 |
|---|---|---|
| 1 | 교정 "아니 ~ / 그거 말고 ~" → 부정어 떼고 새 검색, 직전 스킬 감점 | 아니 지리산에서 찍은 사진 |
| 2 | 좁히기 "그 중에서 ~" → 직전 결과 안에서 | 그 중에 밤에 찍은 것만 |
| 3 | 피드백 → 학습·위치 재검색 | 맞아 / 틀렸어 / 위치로 찾아 |
| 4 | 이어 묻기 → 바꾼 조건만, 나머지 물려받기 | 그럼 작년 거는? / 제주도는? |
| 5 | 앨범 이름 → 그 앨범 안에서 | 쿤 앨범 / 쿤 앨범에서 바다 |
| 6 | **조건 해석** (`query_frame.parse`) | 아래 3장 |
| 7 | 장소 (지역 사전 → 명소 → 사진 지명) | 제주도 / 지리산 / 나가노 |
| 8 | 상황 말 제거 (다른 조건이 있을 때만) | 여행·놀러·휴가·출장 |
| 9 | 내용 해석 (스킬 → LLM) — 남은 내용어가 있을 때만 | 강아지, 바다 |
| 10 | 검색 + 완화 사다리 + 답변·설명 | |

## 3. 조건 유형 (규칙 — `query_frame.py`)

### T. 촬영 시기
| ID | 표현 | 해석 |
|---|---|---|
| T1 | 2019년, 2019년도 | 그 해 전체 |
| T2 | 2025년 5월 | 그 달 |
| T3 | 3월, 지난 3월 | 가장 최근에 지나간 그 달 |
| T4 | 2025년 5월 3일, 5월 3일 | 그 날 (연도 없으면 지나간 가장 최근의 그 날) |
| T5 | 올해·작년·재작년·지난달·이번 달 | 해당 범위 |
| T6 | N년/개월/주/일 전 | 그 시점 주변 |
| T7 | 최근 N일·주·달·년, 지난 N주간, 최근 일주일 | 지금부터 거꾸로 N |
| T8 | 오늘·어제·그제(그저께) | 그 날 |
| T9 | 이번 주·지난주·이번/지난 주말 | 월~일 기준 주 / 토·일 |
| T10 | 봄·여름·가을·겨울 (+연도) | 해당 달(3-5/6-8/9-11/12-2), 연도가 있으면 그 해 안에서 |
| T11 | 새벽·아침·오전·점심·오후·저녁·밤 + **에/무렵/쯤** | 시간대 (조사 없으면 내용어: "저녁 사진"=음식) |

### U. 올린 시기 — 촬영일과 다르다
라이브러리에 들어온 시각(`media.added_at`, 업로드·백업·복사 시각; 기존 사진은 파일 ctime).

| ID | 표현 | 해석 |
|---|---|---|
| U1 | 최근 업로드된·올린·올라온·추가된·백업된, 새로 추가된, 요즘 올린 | 올린 시각 최신순 |
| U2 | 오늘·어제 올린/백업된 (T의 시기 표현 + 올린 동사) | 그 기간에 **들어온** 사진 (촬영일 무관) |
| U3 | 최근 일주일 동안 업로드한 | 지금부터 7일 안에 들어온 사진 |

"받은·저장된"은 올린 시기로 보지 않는다("선물 받은 꽃" 같은 내용 표현과 겹침).

### O. 정렬·개수
| ID | 표현 | 해석 |
|---|---|---|
| O1 | 가장 오래된·옛날·예전·처음 찍은·첫 사진 | 촬영일 오래된 순 |
| O2 | 최근·최신·요즘·마지막으로 찍은 | 촬영일 최신순 (기본값과 같음) |
| O3 | N장·N개 (+만/정도) | 상한 N (최대 1000) |

내용 검색과 함께면("가장 오래된 강아지 사진") 관련도로 고른 뒤 그 순서로 정렬.

### A. 속성·종류
| ID | 표현 | 해석 |
|---|---|---|
| A1 | 즐겨찾기한·좋아요 누른·하트·별표·최애 | 즐겨찾기만 |
| A2 | 동영상·영상·비디오 | 동영상만 |
| A3 | 사진만 | 동영상 제외 ("사진"만으로는 거르지 않는다 — 모든 질의에 붙는 말) |
| A4 | 스크린샷·스샷·캡처 | 파일·폴더 이름에 Screenshot/스크린샷/Capture가 있는 것 |

## 4. 조건 밖의 유형 (기존 경로)

| ID | 유형 | 예 | 처리 |
|---|---|---|---|
| P1 | 지역 | 제주도, 일본, 도쿄 | 지역 사전 → GPS 범위 (나라는 여러 상자) |
| P2 | 명소 | 지리산, 불국사, 한라산 | GeoNames 산·공원·명소 → 중심+반경 |
| P3 | 사진 지명 | 산청, 시천면 | 역지오코딩 지명(시·군·읍·면 한글명 병기) |
| P4 | 해외 동네 | 나가노 | 한글 → 영어 표기로 사진 지명 일치 |
| C1 | 보이는 내용 | 강아지, 바다, 노을, 케이크 | 이미지 의미 검색 (+코멘트·캡션·OCR) |
| C2 | 상황 말 | 여행·놀러·나들이·휴가·출장·가족여행 | 다른 조건이 있으면 뺀다, 혼자면 내용으로 |
| C3 | 고유명사 | 씨메르, 영수증 글자 | 앨범명·코멘트·폴더·OCR 이름 일치 |
| W | 인물 | 민준이 사진 | 얼굴 인물 이름 |
| L | 앨범 | 쿤 앨범 | 앨범 안에서 (5단계) |
| D | 대화 | 그 중에서 / 그럼 ~는? / 아니 ~ / 맞아 | 2장의 1~4단계 |
| X | 비검색 | 안녕, 고마워 | 인사·피드백 응답 |

## 5. 조합 규칙

- 서로 다른 종류의 조건은 **AND**: "작년 여름 제주도 바다 사진 10장" = 2025년 ∧ 6-8월 ∧ 제주 GPS ∧ 내용 '바다' ∧ 10장.
- 같은 종류가 둘이면 **먼저 나온 하나만** (예: 날짜 표현 둘 → 앞의 것).
- 올린 동사가 있으면 시기 표현은 **올린 시기**로 간다 ("오늘 올린" ≠ "오늘 찍은").
- 결과 0장이면 완화 사다리(기간 넓히기 → 위치를 지명으로 → 날짜 빼기 → GPS 장소는 내용 빼기 →
  장소 빼기 → 영어 재시도 → 가까운 시기)로 한 단계씩 넓히고, 무엇을 넓혔는지 답한다.

## 6. 응답 형식

- 답변 문장: `{해석} 찾았어요. 모두 N장이에요.` — 조건만이면 `최근 올린 사진을 찾았어요.` 등
- 상한에 걸리면: `모두 1,780장이에요. 그중 최근 1,000장을 보여드려요.` / 개수 요청: `가장 오래된 10장을 보여드려요. (조건에 맞는 사진은 모두 3,895장)`
